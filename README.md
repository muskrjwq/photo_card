# 포카포켓 (PocaPocket)

포토카드 명부, 무료 온디바이스 이미지 인식, 개인 수집 앨범을 한 프로젝트에 담은 오픈소스 팬 툴입니다. 실제 포카 이미지 대신 리센느 예시 메타데이터와 플레이스홀더가 포함되어 있습니다.

## 핵심 기능

- 멤버·단체·유닛, 앨범·이벤트, 출처, 희소성 등 확장 가능한 태그 기반 명부
- 사진 촬영/업로드 후 사전 등록 포카와 기기 내 매칭
- 명부식 또는 촬영식 수집 모드, 미인식 포카의 비공개 보관 및 추가 요청 흐름
- 포카 바인더 스타일의 `나의 포카`, 수집률·소장자 수·공개 앨범
- 원본·블러·소장자만 원본 공개 이미지 정책
- 기능 플래그와 독립 명부 모듈로 팬사이트별 자유로운 구성

## 빠른 시작

```bash
npm install
npm run dev
```

Node.js 22.13 이상이 필요합니다. 배포 빌드는 `npm run build`로 만듭니다.

## 프로젝트 구조

```text
app/                     웹 진입점과 전역 스타일
components/              포카포켓 UI
modules/catalog/         재사용 가능한 명부 코어
  data.ts                예시 포카/멤버/컬렉션 데이터
  types.ts               공개 데이터 타입
  config.ts              기능 및 이미지 정책 기본값
  matcher.ts             무료 이미지 매칭 점수 유틸리티
public/cards/             교체 가능한 예시 이미지
site.config.ts            사이트별 최상위 설정
```

명부만 필요한 프로젝트는 `modules/catalog`을 복사하거나 별도 패키지로 추출할 수 있습니다. UI는 해당 모듈의 공개 타입만 사용합니다.

## 이미지 인식 설계

서버 AI나 유료 토큰을 사용하지 않습니다. 실제 데이터셋을 넣을 때 다음 파이프라인으로 인덱스를 생성합니다.

1. 카드 외곽선 검출 후 2:3 비율로 원근 보정
2. pHash와 HSV 히스토그램으로 전체 명부에서 상위 후보만 선별
3. OpenCV.js ORB 특징점과 Hamming KNN으로 정밀 비교
4. RANSAC homography의 인라이어 비율로 오매칭 제거
5. 확신도가 낮으면 강제 매칭하지 않고 `감춤` 상태와 추가 요청 선택 제공

이 구조는 조명 변화에는 색상 정규화와 pHash, 기울기·회전에는 ORB와 homography로 대응합니다. OpenCV.js는 브라우저 WebAssembly에서 실행되므로 사진을 외부 서버로 보낼 필요가 없습니다. 정확도 검증은 실제 포카 원본과 다양한 촬영 샘플이 들어온 뒤 데이터셋 기준으로 임계값을 보정해야 합니다.

권장 운영값: 512px 정규화, ORB 800 특징점, Lowe ratio 0.75, 최소 good match 18, RANSAC reprojection 4px, 인라이어 비율 0.35 이상. 저사양 모바일에서는 pHash 상위 20장에만 ORB를 실행하세요.

## 데이터 추가

`modules/catalog/data.ts`의 `CatalogCard` 항목과 `public/cards` 이미지를 추가합니다. 운영 환경에서는 JSON/CSV 가져오기 어댑터나 D1/PostgreSQL 저장소 구현으로 교체할 수 있습니다. 이미지는 저작권 정책에 따라 원본, 일괄 블러, 소장자만 원본 중 하나를 선택하세요.

## 기능 설정

`site.config.ts`에서 `recognition`, `collections`, `publicAlbums`, `requests`, `blurUnowned`를 켜거나 끌 수 있습니다. 저장소 구현과 인증은 어댑터 경계에 두어 정적 명부만 배포하는 구성도 유지할 수 있습니다.

## 현재 데모 범위

검색, 필터, 소장 체크, 앨범 UI, 이미지 공개 정책과 OpenCV.js 기반 실제 업로드 매칭이 동작합니다. 현재 참조 이미지는 플레이스홀더이므로 실물 촬영 정확도를 평가할 수 없습니다. 운영 전에는 실제 원본·다양한 조명과 각도의 검증 세트로 임계값을 보정하고, 관리자 업로드·검수 API와 영속 저장소를 연결해야 합니다.
