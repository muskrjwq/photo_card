# 이미지 인식 인덱스

`npm run catalog:generate`는 `data/rescene/rescene_photocards.csv`와 `public/rescene_poca`를 읽어 다음 파일을 생성합니다.

- `rescene-catalog.generated.json`: 포카 명부, dHash, 명암 히스토그램, 16×24 이미지 특징
- `public/rescene-recognition-index.bin`: 포카별 ORB 특징점 좌표와 기술자

이미지 확장자는 고정하지 않습니다. CSV의 `cardId`와 같은 파일명의 실제 이미지를 찾아 사용하므로 PNG, JPG, WebP를 사용할 수 있습니다. 이미지나 메타데이터가 바뀌면 생성 명령을 다시 실행해야 합니다.

## 인식 순서

1. 사진 전체와 카드 외곽·원근을 보정한 사진을 각각 비교합니다. 잘못된 테두리 검출로 정답을 잃는 것을 줄입니다.
2. 밝기를 정규화한 이미지 상관도로 후보 100장을 고릅니다. 작은 위치 차이도 허용합니다. 약한 결과는 저해상도 재비교에서 후보를 300장까지 늘립니다. 충분히 뚜렷한 결과는 조기 종료합니다.
3. 사전 생성된 ORB 기술자와 비교합니다. 하나의 원본 특징점에 여러 점이 붙으면 한 번만 셉니다.
4. RANSAC으로 일치점의 기하 관계와 공간 분포를 검증합니다. 뒤집히거나 비정상적으로 변형된 카드 모양은 제외합니다.
5. 최소 일치점, 인라이어 비율, 공간 범위를 모두 만족한 후보들끼리 비교한 뒤 결과를 반환합니다.
6. 강한 결과는 유력 결과로 표시하고, 애매한 결과는 상위 후보 4장을 보여 사용자가 직접 선택하게 합니다.

이미지와 인식은 브라우저 안에서 처리되며 외부 AI API나 토큰을 사용하지 않습니다.

바이너리 URL에 내용 해시를 붙여 이전 캐시와 구분합니다. 인식 점수는 비교용 지표이며 정답 확률이 아닙니다.

## 회귀 테스트

`public/poca_test/<cardId>.jpg`에 실물 사진을 넣고 `npm run test:recognition`을 실행합니다. ID의 대소문자는 구분하지 않습니다. ID 형식이 아닌 사진은 정확도 집계에서 제외합니다.

PowerShell에서 열화 테스트도 실행하려면:

```powershell
$env:STRESS = '1'
npm run test:recognition
```

열화 조건: 360×540 축소, 밝기 55%, 채도 70%, 흐림, 기울임, 14도 회전, JPEG 품질 35. 무관한 그림과 단색 이미지의 거부도 확인합니다. 원본 사진은 수정하지 않습니다.

테스트는 운영 매처를 OpenCV로 실행하며 이미지 디코딩만 Sharp로 대체합니다. 브라우저 UI 검증을 대신하지는 않습니다. 결과는 `outputs/recognition-test.json`에 저장됩니다. 정답이 1순위가 아니거나 음성 사례를 받아들이면 종료 코드 1을 반환합니다. 합성 열화 결과가 모든 실제 촬영 환경의 성능을 보장하지는 않습니다.
